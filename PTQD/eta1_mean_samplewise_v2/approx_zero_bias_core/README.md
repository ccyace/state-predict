# 剩余条件偏差是否可以近似视为零：核心尺度实验

## 检验目标

本实验不要求剩余残差的条件均值在统计检验中严格等于零，而是检验其影响
是否相对于：

1. 剩余残差的中心方差；
2. generalized-DDIM eta=1 的随机方差预算；

足够小。

仅使用最稳定、样本量最充足的条件分组：

```
g = nominal timestep x RGB channel
```

数据为 100 条 held-out 轨迹、9,600 个状态。分析对象是 eta=1 专用均值头
全强度校正后的理论剩余残差：

```
r = epsilon_fp - epsilon_q_dt - mean_net(...)
```

## 指标

条件偏差相对中心方差：

```
kappa_g = mu_g^2 / Var(r | g)
```

条件偏差映射到 DDIM 状态更新后，相对采样器随机预算：

```
gamma_g = B_t^2 mu_g^2 / sigma_t^2
```

中心残差方差的 VSC 预算占用率：

```
rho_centered = B_t^2 Var(r | g) / sigma_t^2
```

同时比较直接使用 MSE 与使用中心方差估计 VSC 预算的差异。

## 核心结果

### 条件偏差/中心方差比 kappa

| 指标 | 数值 |
|---|---:|
| median | 8.33e-5（0.00833%） |
| p90 | 9.78e-4（0.0978%） |
| p95 | 1.818e-3（0.1818%） |
| max | 1.270e-2（1.270%） |
| 小于 0.1% 的组 | 90.28% |
| 小于 1% 的组 | 99.65% |
| 小于 5% 的组 | 100% |

按照预设的 `p95(kappa) < 1%` 标准，条件偏差相对于剩余残差方差可以忽略。
虽然存在一个极端时间/通道组略高于 1%，但不影响 p95 结论。

### 条件偏差/DDIM随机预算比 gamma

| 指标 | 数值 |
|---|---:|
| median | 6.55e-9 |
| p90 | 8.75e-8 |
| p95 | 1.67e-7 |
| max | 4.54e-6 |
| 小于 0.1% 的组 | 100% |

按照预设的 `p95(gamma) < 1e-3` 标准，条件偏差引起的状态更新能量相对于
eta=1 随机预算完全可以忽略。实际 p95 比该阈值低约四个数量级。

### 使用 MSE 作为协方差代理的误差

残差 MSE 包含 `centered variance + squared bias`。若直接用 MSE 做 VSC，预算
相对高估为：

| 指标 | 数值 |
|---|---:|
| median | 0.00840% |
| p90 | 0.0986% |
| p95 | 0.1835% |
| max | 1.254% |
| 高估小于 1% 的组 | 99.65% |

因此在当前时间×通道标量统计下，直接用残差 MSE 代替中心方差造成的误差
非常小；严格实现仍建议先减去分组均值再估计方差。

### 中心残差方差占用随机预算

| 指标 | 数值 |
|---|---:|
| median | 5.26e-5 |
| p95 | 3.55e-3（0.355%） |
| max | 3.53e-2（3.53%） |
| 小于 1% 的组 | 97.89% |

这再次表明 eta=1 的随机预算远大于当前 W8A8 剩余误差。

## 可以形成的结论

尽管逐时间条件均值图中部分置信区间不包含零，但其统计显著性不等于实际
影响显著。尺度实验表明：

> 在时间步×通道条件分组下，剩余量化误差的条件偏差能量 p95 仅占中心残差
> 方差的 0.182%，且其 DDIM 状态更新能量 p95 仅占 eta=1 随机预算的
> 1.67e-7。因此在局部标量二阶矩校准意义下，可以将该条件偏差近似视为零。

推荐论文使用“negligible conditional bias”或“approximately centered”，不要写成
严格证明 `E[r|c]=0`。

## 结论边界

该实验只证明：

- 时间步×通道的标量均值偏差可忽略；
- eta=1、当前 W8A8、当前均值头和 held-out 轨迹范围内成立。

它不证明：

- 完整像素场条件均值为零；
- 给定完整高维状态后的条件均值为零；
- 残差高斯；
- 残差跨时间独立；
- VSC 一定改善 FID。

后两点仍受此前重尾、长程相关以及 time-only VSC FID 无收益结果限制。
